# AI-Knowledge-Vault

An AI-powered learning assistant for managing documents, extracting knowledge, and generating insights.

## 🚀 Current Status: MVP Phase
We are currently in the initial **MVP (Minimum Viable Product)** design and development phase. The core features we are building include:
- Document Ingestion (PDF Uploads)
- Smart AI Chat with Vector Search
- Automated Flashcards & Quizzes

## 🛠️ Planned Tech Stack
- **Frontend:** Next.js & React (Vanilla CSS)
- **Backend:** Python (FastAPI)
- **AI/ML Infrastructure:** LangChain & PostgreSQL (`pgvector`)
